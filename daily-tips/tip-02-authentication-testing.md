# 🔐 Security Tip #2 – Authentication Testing (Overview)
## 🔑 What is Authentication?

Authentication is the process of verifying the identity of a user or system. In web applications, this is typically done through login mechanisms using one or more authentication factors.

## 🎯 Testing Goal

Understand how authentication works and attempt to bypass or weaken it through design or implementation flaws.

## 📌 Core Authentication Tests
- OTG-AUTHN-001 – Credentials over encrypted channels
- OTG-AUTHN-002 – Default credentials
- OTG-AUTHN-003 – Weak lockout mechanisms
- OTG-AUTHN-004 – Authentication bypass
- OTG-AUTHN-005 – Remember-me functionality
- OTG-AUTHN-006 – Browser cache weaknesses
- OTG-AUTHN-007 – Weak password policy
- OTG-AUTHN-008 – Weak security questions
- OTG-AUTHN-009 – Password reset weaknesses
- OTG-AUTHN-010 – Weaker alternative authentication channels
